### 👨‍💻 Über mich

Ich bin Fachinformatiker für Systemintegration (FiSi) in Ausbildung und leidenschaftlicher Homelab- & Self-Hosting-Enthusiast. Auf meinem YouTube-Kanal **Felix-Lab** teile ich Setups, Tutorials und Automatisierungen rund um Linux, Docker und Heimserver.

* 🔭 **Aktuelle Projekte:** Homelab-Automatisierung, Linux-Server-Skripte & ZimaOS
* 📺 **Content Creator:** Tutorials & Setups auf [Felix-Lab](https://www.youtube.com/@Der_Felix_Lab)
* 🌐 **Websites:** [cubik-systems.de](https://cubik-systems.de) • [socials.felix-lab.eu](https://socials.felix-lab.eu)
* ⚡ **Motto:** Kein Problem, das man nicht mit einem Container oder Bash-Skript lösen kann.
